# SSGO Web v0.55

## Исправление: разный расчёт на разных компьютерах
Причина: GLTFLoader подгружал A1.bin по ссылке ВНУТРИ .gltf без cache-bust.
На компьютере со старым кэшем браузер отдавал СТАРЫЙ A1.bin (старый рельеф),
поэтому core cut был завышен (15 308 вместо 13 920), хотя кривые/диагностика совпадали.

Исправление: loader.setURLModifier добавляет ?t=<token> к .bin при каждой загрузке склона.
Теперь terrain всегда свежий.

Разовое действие на проблемном компе: Ctrl+F5 (жёсткое обновление), чтобы сбросить старый кэш.
