# SSGO Web v0.50

## Линейка исправлена
Причина: clearMeasure() вызывался при КАЖДОМ клике и стирал первую точку.
Теперь новая точка добавляется к текущему измерению; новое измерение начинается
только после завершённого (2 точки).

- Плавающая кнопка справа внизу (как Home): 📏, жёлтая когда активна.
- 2 клика -> пунктир + подпись: 3D-расстояние, горизонтальное, перепад высот.
- Выключение линейки убирает линии.
