# SSGO Web v0.52

## Прозрачность лейблов — исправлена
Раньше opacity применялся, но из-за тёмной подложки спрайта эффект был почти незаметен
и менял только сортировку прозрачности. Теперь:
- ползунок 0-100%, эффект квадратичный: 50% -> 25% непрозрачности;
- при 25% и ниже подписи полностью скрываются (visible=false);
- действует на подписи уклонов/высот, оригинальные высоты и линейку;
- применяется сразу и после пересчёта;
- depthWrite=false — без артефактов сортировки.

## Линейка
- После 2 кликов следующее измерение стирает предыдущее.

Точные Maya-станции, raycast-сэмплинг, профиль из рельефа.
