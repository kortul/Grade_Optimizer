# SSGO Web v0.39

## Что изменено
- `crossfall` теперь корректно трактуется как проценты: внутри `design()` делится на 100.
- `offset` оставлен вертикальным сдвигом профиля, как в Maya.
- Станции создаются равномерным ресемплингом по длине центральной кривой, как в Maya: `ceil(length / spacing) + 1`.
- `evaluate()` возвращает `nforced` и Maya-совместимый `score`.
- Добавлен оптимизатор `offset` / `crossfall`: coarse 13 x 9, затем refine.
- В Advanced добавлены параметры Maya; для A1 по умолчанию `offset=-0.75`, `crossfall=+0.264`.
- Добавлена кнопка «ОПТИМИЗИРОВАТЬ offset / crossfall».

## Деплой на GitHub Pages
Загрузите в корень репозитория `GradeOptimizer/Grade_Optimizer`:

- `index.html`
- `app.v39.js`
- существующие файлы из `assets/` оставьте без изменений:
  - `A1.gltf`
  - `A1.bin`
  - `A1.curves.json`
  - `A1_labels.json`
  - `slopes.json`

Старые `app.v25.js` … `app.v38.js` и `main.js` можно удалить, чтобы не оставлять устаревшие точки входа.

## Проверка
Откройте сайт, выберите A1 и нажмите **ПРИМЕНИТЬ** с настройками по умолчанию.

Ожидаемый ориентир Maya:
- станции: 94;
- лучи: 222;
- срезано: 14 182 м³;
- насыпано: 12 765 м³;
- баланс: -1 м³.

Затем нажмите **ОПТИМИЗИРОВАТЬ offset / crossfall** и сравните результат с Maya.
