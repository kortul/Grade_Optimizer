# SSGO Web v0.42

## Ключевое исправление
Длина кривой и ресемплинг станций теперь считаются в 3D (X,Y,Z), как `cmds.arclen` в Maya.
Раньше длина считалась только по XZ: 450 м в плане давали 92 станции вместо 94.
Перепад высот около 90 м добавляет примерно 10 м 3D-длины, поэтому Maya получает 94 станции.

## Деплой
Загрузите в корень репозитория:
- index.html
- app.v42.js
- assets/A1.curves.json, экспортированный Maya v17.23 (1000 точек)
