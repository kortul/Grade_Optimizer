# SSGO Web v0.45

## Подписи
Возвращён старый красивый стиль v26: спрайты 384x96 с полупрозрачной подложкой,
те же размеры и расположение. Исправлен баг, из-за которого 3D-подписи вообще не создавались
(сравнение c[2] у 2D-массива eng.C).

## Движок
- Профиль оси из высот рельефа, как в Maya.
- Crossfall: design принимает долю; ручной режим делит проценты один раз.
- Точные Maya-станции (centre_stations/left_stations/right_stations) используются напрямую.
- Оптимизатор offset/crossfall с Maya-score.

## Деплой
index.html + app.v45.js в корень; A1.curves.json от Maya v17.24 с точными станциями.
