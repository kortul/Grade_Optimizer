# SSGO Web v0.48

## Главное: единый метод сэмплинга рельефа
Раньше движок использовал ДВА разных метода: barycentric-сэмплер по геометрии GLTF (62 из 94
станций) и raycast (32 из 94). Если barycentric-сэмплер работал в другой системе координат
(локальной вместо мировой), он давал неверные высоты — отсюда кривой склон и завышенные объёмы.

Теперь ВСЁ сэмплирование (профиль оси, TG core, лучи откосов) идёт через один raycast
с кэшем — тот же метод, который в Maya-проверке совпал с TriSampler до 0.00001 м.
