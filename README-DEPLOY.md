# SSGO Web v0.51

## Линейка
- После завершённого измерения (2 клика) следующий клик стирает старую линию и начинает новое.
- Плавающая кнопка справа внизу, жёлтая когда активна.

## Прозрачность лейблов
- В легенде под "Тени" добавлен слайдер "Лейблы" (20-100%).
- Действует на подписи уклонов/высот, оригинальные высоты и подписи линейки.
- Применяется сразу и после пересчёта.

## Движок (без изменений)
Точные Maya-станции, raycast-сэмплинг, профиль из рельефа.
Совпадение с Maya v17.24: 14 182 / 12 765 м³, core 13 920 / 11 443, баланс -1 м³.

## Деплой
index.html + app.v51.js в корень; A1.curves.json от Maya v17.24.
