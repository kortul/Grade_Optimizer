# SSGO Web v0.41

## Изменения
- crossfall переводится из процентов в долю.
- offset — вертикальный сдвиг профиля, как в Maya.
- Кривые сглаживаются Catmull-Rom и ресемплируются по длине.
- Полный evaluate/score и оптимизатор offset/crossfall.
- В статистике показаны core cut/fill для сверки с Maya (13920 / 11443 м³).
- Добавлена ширина коридора в Debug.

## Деплой
Загрузите в корень репозитория index.html и app.v41.js. Папку assets/ не менять.

## Важно для точного числа станций
В Maya в `export_web()` замените:
`MG.curve_points(crv, 200)`
на:
`MG.curve_points(crv, 1000)`
для centre/left/right, затем заново экспортируйте `A1.curves.json`.
Сейчас полилиния из 200 точек даёт 450.3 м, тогда как Maya имеет 94 станции, что соответствует длине около 460–465 м.
