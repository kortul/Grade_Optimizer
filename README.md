# SSGO Web — Баланс грунта

Статический сайт (без сборки) для подбора параметров склона клиентом. Хостинг: GitHub Pages (бесплатно).

## Структура
- `index.html` — страница и панель параметров
- `main.js` — Three.js сцена + упрощённый расчёт срез/насыпь
- `assets/slope1.glb`, `assets/slope2.glb` — ваши склоны (кладёте сами)

## Подготовка GLB в Maya
На каждый склон: terrain mesh + 3 кривые (centre, left, right) + замкнутая кривая outer limit.
В именах объектов должны быть слова: `terrain`, `centre` (или `center`), `left`, `right`, `limit`.
Экспорт: glTF/GLB. Сохранить как `assets/slope1.glb` и `assets/slope2.glb`.

## Публикация на GitHub Pages
1. Создайте репозиторий (например `ssgo-web`) и загрузите все файлы из этого архива.
2. Положите ваши GLB в папку `assets/`.
3. Settings → Pages → Source: ветка `main`, папка `/ (root)` → Save.
4. Через 1-2 минуты: `https://<логин>.github.io/ssgo-web/`

Локальная проверка: в папке запустить `python -m http.server 8000` и открыть http://localhost:8000
(через file:// GLB не загрузится — браузер блокирует).

## Статус
Превью с упрощённым расчётом (по центральной линии). Полный порт ядра из Python — следующий этап.
Кнопка «Сохранить» скачивает JSON-пресет с параметрами.
